# An-lises_TCCs_AED1
Análise de redes de conhecimento de 15 TCCs de Engenharia de Computação da UFRN. Utiliza PLN (NER) e Teoria dos Grafos para mapear o ecossistema tecnológico do curso, destacando tendências como Python e IA Generativa, além de avaliar o impacto de diferentes janelas de contexto na topologia da rede.
