# 📂 Origem dos Dados (Corpus de TCCs)

Devido às políticas de limite de tamanho de armazenamento do GitHub e para manter este repositório leve e ágil, os **15 arquivos PDF originais** utilizados nesta análise não foram incluídos diretamente nesta pasta.

### 🔍 Onde encontrar os dados originais?
Todos os Trabalhos de Conclusão de Curso (TCCs) processados neste projeto são documentos públicos e foram obtidos através do **Repositório Institucional da UFRN (Universidade Federal do Rio Grande do Norte)**.

O corpus é composto por monografias de alunos concluintes do curso de **Engenharia de Computação**.

### 🛠️ Como reproduzir a análise?
Se você deseja clonar este repositório e rodar o código do zero:
1. Baixe monografias em formato `.pdf` do repositório da sua instituição (ou da UFRN).
2. Coloque os arquivos baixados dentro desta pasta `data/`.
3. O script no notebook (Bloco 2) irá iterar automaticamente sobre todos os PDFs contidos aqui, extrair os textos e gerar os grafos globais.

> **Nota:** Para testes rápidos, você pode adicionar apenas 1 ou 2 PDFs de exemplo nesta pasta e rodar o pipeline.
